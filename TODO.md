# Что сделать

Список ведётся под публикацию в Miro Marketplace, но большая часть пунктов полезна сама по себе, без витрины.
Требования сверены с документацией Miro от 13.08.2026.

## 1. Англификация интерфейса

Панель целиком на русском: кнопки, справка, настройки игрока, диагностика, тексты ошибок парсера,
`<html lang="ru">` в [index.html](index.html). Ревьюер Miro не сможет пройти основной сценарий, а сообщество за
пределами партии — просто не поймёт панель.

- [ ] Вынести строки из компонентов в один словарь (сейчас они вшиты в JSX по всему `src/ui`).
- [ ] Английский перевод: `DiceBar`, `FormulaBar`, `Presets`, `RollLog`, `PlayerSettings`, `Help`, `Diagnostics`,
      `StatusBar`, а также сообщения `DiceError` из [src/dice](src/dice).
- [ ] Английский — язык по умолчанию, русский — переключателем; выбор хранить в `localStorage` рядом с прочими
      настройками игрока.
- [ ] Проставлять `lang` на `<html>` по выбранному языку.
- [ ] Английское имя приложения для витрины. Конвенция Miro жёсткая: `<Имя> for Miro` («Dice Roller for Miro» —
      можно, «Miro Dice Roller» — забракуют).
- [ ] Не забыть про подпись броска после двоеточия и синтаксис формул: `d20adv`, `kh3` и прочее уже английские,
      их трогать не нужно.

## 2. Навигация и доступность

Miro проверяет клавиатурную навигацию и работу со скринридером отдельным пунктом ревью.

- [ ] Перетаскивание пресетов ([Presets.tsx:180](src/ui/Presets.tsx:180)) — без клавиатурной альтернативы.
      Нужны стрелки или кнопки «выше/ниже» на сфокусированном чипе.
- [ ] Ловушка фокуса в модалках `Help` и `PlayerSettings`: `role="dialog"` и Escape есть, но Tab уходит за
      пределы окна в панель под ним.
- [ ] Возврат фокуса на кнопку, открывшую модалку, после закрытия.
- [ ] Результат броска объявлять через `aria-live` — сейчас для скринридера бросок молча не происходит.
- [ ] Пройти всю панель с клавиатуры без мыши: бросок, сохранение, правка, удаление, настройки, справка.

## 3. Хостинг — план

GitHub Pages **не проходит** обязательные требования Miro по заголовкам, и починить это на площадке нельзя:
свои заголовки она не отдаёт. Замер `curl -I https://alkochyn.github.io/moon-dice/`:

| Заголовок | Требует Miro | GitHub Pages сейчас |
| --- | --- | --- |
| `Strict-Transport-Security` | `max-age=31536000; includeSubDomains; preload` | `max-age=31556952`, без `includeSubDomains` и `preload` |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | нет |
| `X-Content-Type-Options` | `nosniff` | нет |
| `Cache-Control` | `no-cache, no-store` | `max-age=600`, задать нельзя |

Плюс площадка сама ставит `Access-Control-Allow-Origin: *`. Проверять будут через securityheaders.com, то есть
по факту отдачи, а не по обещаниям.

Отсюда план:

- [ ] Купить домен. Он же развязывает адрес приложения от площадки: переезд станет сменой DNS, а не
      переустановкой приложения у всех игроков.
- [ ] Поднять VPS с nginx, сертификат Let's Encrypt, автопродление.
- [ ] Довести [deploy/nginx.conf](deploy/nginx.conf) до требований: сейчас нет HSTS, стоит `Referrer-Policy:
      no-referrer` вместо требуемого `strict-origin-when-cross-origin`, `Cache-Control` не `no-store`, нет
      `Permissions-Policy`. CSP с `frame-ancestors` вместо `X-Frame-Options` — здесь всё верно, для встраиваемой
      панели Miro сам это оговаривает.
- [ ] Проверить TLS через ssllabs.com (нужен TLS 1.2+) и заголовки через securityheaders.com.
- [ ] GitHub Pages оставить зеркалом: из Москвы открывается за 209–242 мс и пережил все замеры у всех игроков.
- [ ] Офлайн-кэш при этом не ломается: `no-store` касается кэша браузера, Cache API в service worker хранит
      ответ независимо от директив.

## 4. Privacy policy

Обязательное поле листинга, сейчас её нет. История у проекта сильная: своего сервера нет, всё живёт в
`miro.board.storage` и `localStorage`, аналитики нет, третьим лицам ничего не уходит.

- [ ] Написать и выложить на своём домене публичной страницей.
- [ ] Описать честно: в журнал доски попадает имя из `getUserInfo()` и хранится до 200 записей
      ([src/board/log.ts](src/board/log.ts)) — данные не покидают Miro, но умалчивать об этом нельзя.
- [ ] Перечислить скоупы и зачем каждый: `boards:read`, `boards:write` — общий журнал и общие пресеты,
      `identity:read` — только имя игрока.
- [ ] Удаление данных в течение 14 рабочих дней после удаления приложения — требование политики Miro. У нас
      данные уходят вместе с доской, локальные — очисткой браузера; это и написать.
- [ ] Ссылку на политику добавить в настройки приложения Miro и в панель.

## 5. Ассеты листинга маркетплейса

- [ ] Скриншоты: 1–6 штук, PNG/GIF до 8 МБ, максимум 1258×706, full bleed без скруглений и полей, **без белого
      и светло-серого фона** (панель светлая — нужна подложка), текста не больше 1–2 строк и 20% площади,
      логотипов на скриншотах быть не должно. Есть публичный Figma-шаблон Miro.
- [ ] Видео — только YouTube, mp4 не принимают.
- [ ] Описание строго до 450 символов: ключевые фичи и инструкция по установке.
- [ ] Логотип для витрины. Текущий [public/icon.svg](public/icon.svg) сделан под тулбар (`currentColor`, без
      фона) — для маркетплейса нужен отдельный цветной.
- [ ] Ссылки: лендинг, privacy policy, справка, контакт поддержки.
- [ ] Профиль разработчика: логотип, имя, описание, страна, публичный email.

## 6. Мелочи по коду

- [ ] [public/probe.html](public/probe.html) уезжает в `dist` и с продакшн-домена стучится на unpkg, jsDelivr и
      прочие хосты. Для отладки в партии вещь незаменимая, но ревью по безопасности смотрит egress-трафик.
      Исключить из прод-сборки, оставить в дев-режиме или под отдельным деплоем.
- [ ] Обновить vite: `npm audit` показывает 5 уязвимостей (1 critical, 1 high) в dev-зависимостях —
      vite ≤6.4.2 и esbuild. В бандл они не попадают (`npm audit --omit=dev` чист), но OWASP Dependency-Check,
      который Miro прямо называет в гайдлайнах, гоняется по репозиторию.
- [ ] Тёмная тема. [styles.css:23](src/styles.css:23) — тема жёстко светлая, у Miro тёмная доска есть.
      Не требование, но на «UI consistency» это заметно.

## Порог допуска к ревью

Не работа, а условие: Miro не начнёт ревью, пока не будет **>50 MAU в каждом из двух последних подряд месяцев**
и **>10 установок в уникальных организациях**. Подать заявку может только партнёр Miro (сначала Partner Interest
Form), само ревью — 8–12 недель, общение через Jira-тикет.

До этого приложение живёт и работает по installation URL — маркетплейс нужен только ради витрины.
