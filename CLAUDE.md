# Правила проекта

## Язык

- **Названия и описания pull request'ов — только на английском.** Без исключений: заголовок, тело, чеклисты,
  комментарии к ревью. Причина — проект идёт к публикации в Miro Marketplace и к аудитории за пределами партии,
  а история изменений в публичном репозитории это часть лица проекта.
- Сообщения коммитов остаются на русском, как сложилось в истории.
- Комментарии в коде, README и внутренние документы — на русском.
- Строки интерфейса — см. [TODO.md](TODO.md): панель переезжает на английский по умолчанию с переключателем
  на русский.
